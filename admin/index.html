Paste your GitHub access token to edit the website. Changes you save are committed to the site's GitHub repository and go live automatically within a couple of minutes.

Unticked, the token is kept only in this tab. On shared or chapter-house computers, leave it unticked and click Log Out when you finish.

How do I get a token? (one-time setup)
  1. Ask a BZATX owner to add your GitHub account to the BZATX organization as a member (not an outside collaborator) with Write access to theta-xi-auburn-website.
  2. On GitHub go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Set Resource owner to BZATX, not your own account. Set a short Expiration, such as 30 days; when it runs out, make a new token.
  4. Under Repository access choose Only select repositories and pick theta-xi-auburn-website.
  5. Under Permissions, set Contents to Read and write. Leave everything else as "No access".
  6. Generate the token and copy it. GitHub shows it only once. If GitHub says the token needs approval, ask a BZATX owner to approve it (BZATX → Settings → Personal access tokens → Pending requests).
  7. Paste it above. Treat it like a password: don't share it in group chats.
